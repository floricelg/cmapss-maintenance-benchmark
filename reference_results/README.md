# Reference experimental summaries

These files are the retained summaries of the completed 16 October 2026 experimental revision. They include Tables 1 to 13, the four numerical result figures, per-run aggregate metrics, data and duplicate audits, model parameters, feature reliance and uncertainty summaries.

`validation_report.txt`, `independent_metric_validation.csv` and `lineage_validation.csv` describe checks on the original completed runs. They do not certify a new execution on another machine. Raw per-window predictions, checkpoint files and `done.json` caches are not distributed in this directory.

A fresh full run regenerates predictions and summaries in the separate `rezultate/` directory. Compare its tables against these reference tables. The workflow diagram from the manuscript is not a numerical output and is not included.
